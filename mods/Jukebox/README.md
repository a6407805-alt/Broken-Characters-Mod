# Jukebox

Plays the group's Suno songs in game, chosen by a vote.

- Add songs in the launcher: **JUKEBOX** button (top right). Paste a Suno link, press ADD. The launcher downloads
  every song to `%APPDATA%\BrokenCharacters\Jukebox\`, and the mod plays from there.
- A vote opens at the start of each stage and when a song ends. Press **7**, **8** or **9** to vote.
- **J** asks the host for a vote now. **K** (host) stops the music. All keys and the volume are in
  `BepInEx\config\com.brokencharacters.jukebox.cfg`.
- Everyone votes, the host counts, and every player hears the winner from their own copy. Windows only.
