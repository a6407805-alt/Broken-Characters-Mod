# Gravitos NEXT

The owner's rework of Vince's Gravitos (source decompiled from Gravitos 1.2.1; Vince's `mods/Gravitos` is untouched and
both can be installed together).

- **v0.1.0:** new original model, the **Lodestar**: slim floating caster, faceless dome with a violet slit, three iron
  rings orbiting the torso (spin faster while casting) and magnetic shards hovering at the hands. Built in Blender by
  `src/GravitosNext/Blender/build_lodestar.py` → `lodestar_model.bin` + `lodestar_fx.bin`, placed on the Engineer skeleton.
- Kit and numbers are Gravitos 1.2.1 for now (reworks coming).

Config: `BepInEx/config/com.ahren.GravitosNext.cfg`, section **8. Lodestar Model** (model on/off, outline, scale, glow,
ring speed).
