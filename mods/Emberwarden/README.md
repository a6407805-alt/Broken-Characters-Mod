# Emberwarden 0.1.1 (ready to install)

Install: put this whole `Emberwarden` folder (Emberwarden.dll + Sounds) into
`BepInEx\plugins\` of your r2modman profile (Settings > Browse profile folder).
Needs R2API Prefab, Language and ContentManagement (r2modman installs them with R2API).

0.1.1: one "Volume (3)" setting (75) under [CustomSounds] for all four sounds, same level
as the other custom-sound survivors (replaces the four per-skill volumes).
