# BCM Dev Tools (singleplayer only)

Test modded characters and content fast. Turns itself completely off in multiplayer.

- Launcher: **TEST LEVEL** (shows after the game has started once with this mod) = straight into a quiet run on a flat grid floor.
- **F1** free the mouse to click the panel · **F2** show/hide panel
- **F3** god mode · **F4** waves on/off · **F5** spawn enemy · **F7** kill all · **F8** reset cooldowns
- **F9** relaunch the game into the test level · **F10** go to the flat world
- Panel: **Use this survivor** = TEST LEVEL starts as the character you're playing now.
